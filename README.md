# Student Portal
**Live Demo:** https://rahultharun5-ship-it.github.io/student-portal/

A simple web application to manage student records. Made this as my college project for BCA.

## What it does

- Add new students with their details
- View all students in cards
- Search students by name or roll number
- Edit student information
- Delete students
- Shows statistics like total students and average marks

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage for saving data

## How to run

Just open `index.html` in any browser. That's it!

## Features

1. **Add Students** - Click add button and fill the form
2. **View Students** - All students shown in card format
3. **Search** - Type in search box to filter students
4. **Edit/Delete** - Each card has edit and delete buttons
5. **Stats** - Top section shows total students and average GPA

## Screenshots

The interface has a purple gradient background with white cards for students. Search bar at top and stats cards showing numbers.
